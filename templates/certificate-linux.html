A. Create a certificate request on your Linux server

Connect to your server's terminal. Run sudo -i to open a root shell, then copy this block.

umask 077
mkdir /root/plusemu-origin && openssl req -new -newkey rsa:2048 -nodes \
  -keyout /root/plusemu-origin/key.pem \
  -out /root/plusemu-origin/request.csr \
  -subj "/CN={{DOMAIN}}" \
  -addext "subjectAltName=DNS:{{DOMAIN}},DNS:www.{{DOMAIN}},DNS:{{WS_HOST}}"

If the directory already exists, stop and reuse its pending request. Do not overwrite its key after requesting a certificate. All certificate files stay under /root/plusemu-origin, outside the website.

Display the request and copy the complete block, including its BEGIN and END lines.

cat /root/plusemu-origin/request.csr

B. Sign the request in Cloudflare

  1. Open your domain in Cloudflare. Go to SSL/TLS → Origin Server → Create Certificate.
  2. Select Use my private key and CSR. Paste the request you just copied. The private key stays on your server.
  3. Check that all the hostnames listed above are included. Choose a validity period and click Create.
  4. Select PEM as the certificate format. Copy the complete Origin Certificate, including its BEGIN and END lines.

Back in the root terminal, run the command below. Paste the certificate, press Enter, then press Ctrl+D to save it.

cat > /root/plusemu-origin/cert.pem

C. Check and activate the certificate

This block verifies the certificate against Cloudflare's CA, checks the key and hostnames, backs up the existing pair, and reloads nginx. If nginx rejects the new files, it restores the old pair.

bash <<'CERTIFICATE'
set -e
cd /root/plusemu-origin
openssl x509 -in cert.pem -noout -issuer -dates
openssl x509 -in cert.pem -noout -checkend 86400
curl -fsSL https://developers.cloudflare.com/ssl/static/origin_ca_rsa_root.pem -o origin-ca.pem
for host in '{{DOMAIN}}' 'www.{{DOMAIN}}' '{{WS_HOST}}'; do
  openssl verify -CAfile origin-ca.pem -purpose sslserver -verify_hostname "$host" cert.pem
done
openssl pkey -in key.pem -pubout -out key-public.pem
openssl x509 -in cert.pem -pubkey -noout > cert-public.pem
cmp key-public.pem cert-public.pem
backup=$(mktemp -d /etc/ssl/plusemu/backup.XXXXXX)
cp -p /etc/ssl/plusemu/cert.pem /etc/ssl/plusemu/key.pem "$backup/"
echo "Previous certificate and key saved in $backup"
if install -m 600 key.pem /etc/ssl/plusemu/key.pem &&
   install -m 644 cert.pem /etc/ssl/plusemu/cert.pem &&
   nginx -t && systemctl reload nginx; then
  echo 'Certificate installed. Continue with Full (strict).'
else
  cp -p "$backup/cert.pem" "$backup/key.pem" /etc/ssl/plusemu/
  nginx -t && systemctl reload nginx
  echo 'Restored the previous files. Fix the reported error before continuing.'
  exit 1
fi
CERTIFICATE

Confirm that the issuer shown is Cloudflare and that you see Certificate installed. If any check fails, stop and correct the certificate before continuing. The final HTTPS and game checks below verify it through Cloudflare.

Restore the previous nginx certificate

Use the backup directory printed above. Replace backup.XXXXXX with that exact directory name before running this in the root terminal.

cp -p /etc/ssl/plusemu/backup.XXXXXX/cert.pem /etc/ssl/plusemu/backup.XXXXXX/key.pem /etc/ssl/plusemu/ &&
nginx -t && systemctl reload nginx

This restores the previous server files. An old self-signed certificate still cannot pass Full (strict); install a valid origin certificate to finish setup.

When you finish, run exit to leave the root shell. Keep the private key and backup directories private.
