Advanced setup checklist

Complete the same Cloudflare and certificate steps below, with an API token (step 3) or by hand (steps 4 to 6), then review these manual administration tasks. Selecting this guide does not change SSH, RDP, firewall, updates or backups.

  • Administrator access: verify a named administrator and recovery access. On Linux, the installer lets root log in with an SSH key only, and turns SSH password login off only when your login uses an SSH key. If it said that password login stays on, add your SSH key, log in with it and run the installer again to turn password login off. On Windows, an account locks for 10 minutes after 10 wrong passwords in 10 minutes; verify your administrator's remote access and recovery method before restricting RDP or SSH.
  • Firewall: the installer accepts the website only from Cloudflare's addresses (Linux: HTTPS, and the hotel's names over HTTP; Windows: HTTP and HTTPS) and refreshes them every Sunday at 03:00. Keep the DNS records orange (Proxied): with a grey record, the hotel is unreachable. After a refresh, check that the website and the game still connect, and read the log (Linux: /var/log/plusemu-cloudflare-ips.log, Windows: C:\ProgramData\PlusEMU\cloudflare-ips.log). To refresh now, run sudo plusemu-cloudflare-ips on Linux or Start-ScheduledTask 'PlusEMU Cloudflare addresses' on Windows. Review the other public ports and administration access yourself.
  • Maintenance: the installer backs up the database and your settings every night at 04:00 and keeps 7 backups (Linux: /var/backups/plusemu/nightly, Windows: C:\ProgramData\PlusEMU\backups\nightly). Security updates install at 05:00 and restart the server only when an update needs it. Test a restore, and copy the backups to another place now and then: local backups cannot recover a lost server. A health check runs every 5 minutes. It checks the emulator, the game and API ports, the web server and the website, the database, free disk space, the newest backup, the HTTPS certificate and the last Cloudflare address refresh. Run it now with sudo plusemu-health on Linux or & C:\ProgramData\PlusEMU\plusemu-health.ps1 on Windows, and read its log (Linux: /var/log/plusemu-health.log, Windows: C:\ProgramData\PlusEMU\health.log). With a Discord webhook, you get a message when a check starts failing and when it works again. To change the webhook, run the installer again with PLUSEMU_DISCORD_WEBHOOK set to the new URL, or to off.
  • CrowdSec (Linux, optional): when you answered yes, CrowdSec reads the SSH and nginx logs, finds attack patterns such as password guessing, bans those addresses, and shares and uses a blocklist of known bad addresses. It never bans Cloudflare's addresses or this server, and fail2ban is off while it runs. See the bans with sudo cscli decisions list. Unban an address with sudo cscli decisions delete --ip <ip>. Optional: connect it to the free CrowdSec console with sudo cscli console enroll <key>. To turn it on later, run the installer again with PLUSEMU_CROWDSEC=1. The Windows installer does not install CrowdSec: IIS logs Cloudflare's address instead of the visitor's, so CrowdSec would block Cloudflare instead of attackers.

These tasks are not marked complete by the installer. Keep your existing administration connection open while changing access rules.
