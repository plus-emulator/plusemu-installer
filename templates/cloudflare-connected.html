✓ Cloudflare is connected

The installer set up Cloudflare for {{DOMAIN}}:

  • DNS: {{DOMAIN}}{{GAME_ADDRESS_ITEM}} and www.{{DOMAIN}} point to {{SERVER_IP}} through Cloudflare (proxied, orange cloud).
  • Origin certificate for {{DOMAIN}} and *.{{DOMAIN}}, valid until {{CERTIFICATE_EXPIRES}}.
  • SSL/TLS: Full (strict), Always Use HTTPS and TLS 1.2 or newer.
  • WebSockets on, for the game connection.
  • Bot Fight Mode, Browser Integrity Check and security level medium.
  • Rate limit: 10 sign-in, registration and password reset requests per 10 seconds per visitor. Over the limit, Cloudflare blocks that visitor for 10 seconds.
  • Firewall rules: the game connection works only from https://{{DOMAIN}}, and visitors to housekeeping get a Cloudflare check first.

Check it now

  1. Open https://{{DOMAIN}}. The website loads over HTTPS.
  2. Log in with the admin username and password the installer showed you. Change the password under Settings → Password.
  3. Click Enter hotel. The game client opens and connects.

If Cloudflare still shows your site as Pending, wait until it says Active, then check again.

You can delete the API token now: in Cloudflare, open My Profile → API Tokens, click ⋯ next to the token, then Delete. To run the setup again later, create a new token and run the installer again.
